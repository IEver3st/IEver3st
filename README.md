## About

I'm a software builder working across desktop applications, developer tooling, hardware integrations, real-time interfaces, and automation.

I build products and tools under **Means** and **Cortex Software**, with a focus on software that is fast, deliberate, useful, and pleasant to work with.

Most of what I build starts with a workflow, device, or piece of software that annoys me enough to fix properly.

## Current product work

Not everything I build is open source.

**Means Audio**
A Windows companion for Sony WH-1000XM5 and WH-1000XM6 headphones, with device controls, EQ profiles, per-app audio controls, and application-aware sound setups.

**CompressThing**
A local Windows media compressor built around destination-size targets, mixed image/video queues, repeatable presets, and hardware-accelerated processing.

Their application source is private. Public product information and releases live through **[Means](https://frommeans.com/products)**.
